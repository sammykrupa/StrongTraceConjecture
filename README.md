# StrongTraceConjecture
MATLAB code and associated files for the paper "The computational ansatz for convex integration of hyperbolic systems and a resolution of the Strong Trace Conjecture" [https://arxiv.org/abs/2609.09353](https://arxiv.org/abs/2609.09353)

basis_state_space.m -- This script calculates the basis for the tangent space of \mathcal{K}_{F,\eta,q}

check_requirements_T_6_Sol.m -- This script checks symbolically that the T_6 from ChatGPT 5.6 Sol Pro meets our requirements.

checkIncreasingShape.m  -- Classify admissible increasing convex/concave data.

export_solution_latex.m -- This script generates the appendix with the values of the T_N parameters.

factorRankOne3x2Symbolic.m -- Factors each symbolic rank-one 3x2 matrix C(:,:,i) as C(:,:,i) = aCell{i} * bCell{i}.' where aCell{i} is 3x1 and bCell{i} is 2x1.

full_data.mat -- Generated by Numerical_Search_T_N.m -- the same approximate T_6 data that is in the appendix in the manuscript. Load this data into the MATLAB workspace with command load("full_data.mat") to put into the MATLAB workspace all of the variables needed for the rest of the scripts to run
(see https://www.mathworks.com/help/matlab/matlab_env/save-load-and-delete-workspace-variables.html for more on how to save and load workspace variables
). Load this before running Perturb_T_N_Symbolic.m.

less_data.mat -- contains only the parameterization of the T_N (P,C_i,kappa_i) from Numerical_Search_T_N.m and the corresponding appendix of the manuscript. Load this data into the MATLAB workspace with command load("full_data.mat") to put into the MATLAB workspace.

make_big_basis.m -- This script combines the basis for the tangent space of the T_N manifold with the basis for the tangent space of \mathcal{K}_{F,\eta,q}

Numerical_Search_T_N.m -- This is the MATLAB code to numerically find a potential T_N configuration for the p-system, in the space of 3x2 matrices.

Perturb_T_N_Symbolic.m -- This is the script to perturb a numerical solution to the T_N equations found using Numerical_Search_T_N.m into an exact solution which (symbolically) verifies all of the necessary conditions.

symRREFPivotCols.m -- returns pivot column indices and columns for a symbolic matrix R that is already in reduced row echelon form.

T6_full_data.m -- Loads the T_6 found by ChatGPT 5.6 Sol Pro.

test_for_concavity_convexity.m -- This script is used for checking conditions of convexity/concavity for the pressure.

tn_tangent_basis_symbolic.m -- Symbolic basis for the tangent space to the T_N manifold.

T4_GNL_System.pdf -- PDF of the (still unverified) argument from ChatGPT 5.6 Pro for a 2x2 strictly hyperbolic and genuinely  system with a T_4 configuration.

T4_GNL_System.tex -- LaTeX source of the (still unverified) argument from ChatGPT 5.6 Pro for a 2x2 strictly hyperbolic and genuinely  system with a T_4 configuration.

TN_rank_one_GNL.pdf -- PDF of the (still unverified) argument from ChatGPT 5.6 Pro for a 2x2 strictly hyperbolic and genuinely system with rank-one connections.

TN_rank_one_GNL.zip -- LaTeX and python source of the (still unverified) argument from ChatGPT 5.6 Pro for a 2x2 strictly hyperbolic and genuinely  system with rank-one connections.
